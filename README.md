# Salma Akter – Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Structure
- `index.html` – the page
- `css/style.css` – styles
- `js/main.js` – animations, color switcher, certificate preview
- `images/` – portrait and certificate images

## Host on GitHub Pages
1. Create a repository (e.g. `portfolio`) and upload all files, keeping the folders.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Your site will be live at `https://<username>.github.io/<repository>/` after a minute or two.

## To update
- Replace a certificate: put the new image in `images/` and update its `src` in `index.html`.
- Facebook link: in `index.html`, search for `facebook.com` and replace it with the profile URL.
